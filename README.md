# 🛒 ZENJI — Streetwear & Urban Fashion E-Commerce

> **ZENJI** is a high-performance, responsive e-commerce web application designed for a premium streetwear brand. Built with a modern component-driven architecture, it features seamless navigation, dynamic page routing, real-time search, and a sleek dark-themed UI.
